## DMIT Pro 套餐是什么？一句话定义

**DMIT Pro 套餐（又称 Premium 系列）**，是 DMIT 旗下专门针对中国大陆访问做了优化的 VPS 产品线，核心是三网回程 CN2 GIA 线路——电信、联通、移动三条国内运营商线路，回程全走 CN2 GIA（AS4809）这条高速通道，不走普通公网绕路。

跟 DMIT 的其他产品线（Eyeball、Tier 1）最大的区别在于：Pro 系列对国内访问的线路质量做了硬性保证，晚高峰也能维持稳定。Eyeball 和 Tier 1 相对便宜，但线路优先级不同，对速度敏感的场景用起来差距挺明显的。

洛杉矶是 DMIT 套餐最多、库存相对最稳定的机房。LAX Pro 走三网回程 CN2 GIA，去程电信联通直连 CN2，移动走 CMI，整体路由算是 Pro 系列里性价比最能打的一档。

硬件这块，洛杉矶 Pro 系列目前已经升级到 AMD EPYC 9005（AN5 平台），处理器性能比之前的方案提升明显。存储全是企业级 SSD，不是那种混用消费级盘的打法。

IP 被墙之后，每 15 天可以免费换一次，超出这个频率是 $5 一次，相比某些商家收 $20+ 还算合理。

还有一点新手常被坑到的：DMIT 默认 SSH 密钥登录，不是密码。拿到机器第一件事先去控制台 Access 页面把密钥包下载下来，里面有 `.ppk` 供 PuTTY 用。如果不习惯密钥方式，可以重装系统改成密码登录，步骤稍多但不复杂。

洛杉矶 Pro 里有两款限量特供套餐值得单独提：

超量之后限速到 2Mbps，不是直接断服，对于个人轻量使用算是比较友好的机制。

## 不同需求怎么选 DMIT Pro 套餐？

说实话，选套餐这件事没有标准答案，关键是搞清楚自己真正的需求落点在哪。

**预算有限但想体验 CN2 GIA 线路**：盯着 MALIBU 或者 PalmSpring 这类限量特价套餐，年付 $49.9 是这条线路里最低的入场价了。缺点是只有 1G 内存，跑个人博客或者轻量代理够用，想部署稍重的服务就不太够。

**稳定建站、外贸业务，需要长期可靠的美国节点**：选洛杉矶 Pro 常规套餐，TINY 月付 $9.99 算下来每天三毛多钱，性价比在 CN2 GIA 这个级别里算过得去。

**主要服务国内用户、对延迟极度敏感**：香港 Pro，别的都往后排。50ms 以内的延迟跟 150ms+ 的用户体验差距不是一个量级，这个溢价是有实际价值的。

**需要日本 IP 或面向日本市场**：东京 Pro，线路配置跟香港类似，地理位置优势明显。

一个实用的判断思路：如果你在意的是网络稳定性和线路质量，选 Pro；如果预算紧张且对国内访问速度没有硬性要求，Eyeball 或 Tier 1 能省一半以上的钱。两个诉求不在同一维度上，不用非得比较。

## 下单前有几件事要知道

**关于账号等待期**：新注册的 DMIT 账号有 7 天的等待期才能下单，不是针对特定人的设置，所有新账户都一样。有购买计划的话提前几天注册好。

**关于退款政策**：3 天内使用流量不超过 30GB 可以全额退款，超过这个窗口期是按剩余价值退（会扣除支付手续费）。这个政策比很多同类服务商要宽松一点。

**关于 Pro 系列的 IP 被墙问题**：IP 被 GFW 封了之后，每 15 天免费更换一次。不是每次都被封的，但碰到了处理起来不算麻烦。

**关于流量超量**：洛杉矶 Pro 超量后不是断服，而是限速到 2Mbps，可以继续用只是速度很慢。对于跑个人项目来说这个机制相对友好。

**关于支付方式**：DMIT 支持支付宝、微信支付、PayPal，对国内用户来说付款没什么障碍。

顺便提一嘴：DMIT 是搬瓦工的上游供应商，这点很多人不知道。用的是同一套底层网络资源，但自家直卖的价格有时候比搬瓦工的套餐更划算，尤其是碰到补货特价的时候。

## DMIT Pro 系列的高防版本（sPro）是什么？

DMIT 洛杉矶还有一个 Premium Secure 系列，也叫 LAX.sPro，在 Pro 的 CN2 GIA 回程基础上，去程加了 Cloudflare Magic Transit（CFMT）的 DDoS 保护，可以抵御高达 5Tbps 的攻击。

适合有建站需求、或者服务容易遭受攻击的用户。价格比普通 Pro 贵，但防护级别本质上不是一个档次的。普通 Pro 没有专门的去程 DDoS 保护，sPro 的出发点是"业务不能被打垮"，两个产品定位不同。

## 常见问题

**Q：DMIT Pro 套餐适合用来科学上网吗？**

配置上完全没问题，CN2 GIA 线路质量足够稳定，原生 IP 解锁主流流媒体（Netflix、TikTok 等）的概率也比较高，但官方不做这方面的明示保证。用来搭建个人节点的话，延迟和稳定性都交代得过去。

**Q：MALIBU 这类限量套餐啥时候会有货？**

没有固定规律，大促节点（黑五、双十一、圣诞元旦春节前后）出货频率更高，平时也会不定期补货。补货量通常不大，有需求的话关注官网就行，看到有货直接下。

**Q：洛杉矶 Pro 和香港 Pro 哪个更值？**

看你的目标用户在哪里。业务面向国内用户，香港的 20-50ms 延迟明显比洛杉矶的 150ms+ 体验好，而且价格差也大。个人用途（翻墙、建站、跑脚本），洛杉矶 Pro 的性价比更高。

**Q：DMIT Pro 支持 IPv6 吗？**

支持，默认分配 1个 IPv4 + 1个 /64 IPv6。IPv6 走的是 CMIN2 优化线路。

**Q：如果用下来不满意，能退款吗？**

可以，3 天内流量使用不超过 30GB 直接全额退，超过这个时间就按剩余价值退，会有支付手续费。这个窗口期够用来测试线路了。
